## ⚡ Overview

Most financial tools like NerdWallet, Bankrate, or SmartAsset are cluttered with 20+ overwhelming input fields, slow load times, aggressive lead forms, and paywalls. 

**Calcora** reimagines financial calculators through an **Apple Design Philosophy**:
- **OLED Pitch Black** (`#000000`) with vibrant Apple Orange (`#ff9f0a`) accents.
- **2–3 Input "Easy Mode"** with instant answers and plain-English bottom lines.
- **Micro-Interactions & Confetti** for motivating financial milestones.
- ** Quick Calc Widget:** Pop-out interactive keypad anytime.
- **195+ Sovereign Countries:** Dynamic local currencies (`$`, `£`, `€`, `₹`, `¥`), average wages, and housing costs.
- **15+ Native Languages:** Auto-detected country-to-language sync (English, Spanish, Hindi, French, German, Arabic, Chinese, Japanese, etc.) with 1-click override.

## 🚀 The 8 Interactive Engines

### 1. 💼 1099 vs W-2 Contractor Equalizer
- Converts any salaried W-2 role into the exact gross billing rate required as an independent contractor or freelancer.
- Accounts for the **15.3% Self-Employment Tax** (Social Security + Medicare), **Section 199A QBI 20% Deduction**, missing health insurance ($7,500/yr), 401(k) matching, and unpaid PTO.

### 2. 💳 Credit Card Debt Payoff Matrix
- Head-to-head comparison: **Debt Avalanche** (mathematical lowest interest) vs **Debt Snowball** (psychological quick wins) vs **0% Balance Transfer Consolidation**.
- Live amortization curves, exact debt-free dates, and total interest saved vs minimum payments.

### 3. 🏡 2026 Rent vs Buy Decision Engine
- Pits unrecoverable homeownership costs (6.5%+ mortgage interest, property tax, HOA fees, maintenance) against investing down payments in broad-market **S&P 500** index funds.
- Pinpoints the true financial break-even year.

### 4. 🛍️ "Can I Afford This?" (Viral Impulse Checker)
- **Life-Hours Traded:** Converts price into exact working hours and work days of human life traded for an item.
- **S&P 500 Opportunity Cost:** Projects what that purchase price would compound to over 10, 20, and 30 years at 8% CAGR.
- **72-Hour Rule Enforcer:** Smart behavioral delay to eliminate retail buyer's regret.

### 5. 🔥 FIRE Retirement Freedom Calculator
- **Trinity Study 4% Safe Withdrawal Rule:** Calculates the exact lump sum needed for financial independence.
- **Freedom Age Projection:** Simulates month-by-month compounding to forecast the exact retirement year and age.
- **Lean, Coast, & Fat FIRE:** Live breakdown across multiple lifestyle tiers.

### 6. ⚔️ Side-by-Side Job Offer Duel
- Head-to-head showdown between two competing offers (e.g. Austin TX with 0% state income tax vs San Francisco CA with 9.3% tax vs London £).
- Accounts for local rent, 401(k) match, and state tax brackets to reveal the true **Real Disposable Cash Champion**.

### 7. 🏛️ UK 60% Marginal Tax Trap & Salary Sacrifice
- Navigates the HMRC £100k–£125k personal allowance taper (effective 62% marginal tax rate).
- Models pension salary sacrifice to restore personal allowances and protect 30-hour free childcare eligibility.

### 8. 💡 Intelligence & Feature Suggestion Hub
- Actionable tax optimization hacks, S-Corp shielding advice, and an open community upvote roadmap for new calculation engines.

## 🛠️ Tech Stack & Architecture

- **Framework:** React 19 + TypeScript (Strict Mode)
- **Bundler:** Vite 8
- **Styling:** Tailwind CSS v4
- **Icons:** Lucide React
- **Celebrations:** Canvas Confetti
- **SEO & Schema:** Schema.org JSON-LD (SoftwareApplication review stars, FAQPage accordion), dynamic meta tags, and `sitemap.xml`.

## 💻 Getting Started Locally

```bash
# Clone the repository
git clone https://github.com/themridul03/Calcora.git

# Enter project directory
cd Calcora

# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build
```

Open [http://localhost:5173](http://localhost:5173) in your browser.
